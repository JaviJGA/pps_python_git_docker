# pps_python_git_docker

App para sacar frases motivadoras aleatorias al estilo madre cuarentona, usando MongoDB.

La aplicación estará disponible en <http://localhost:5000>

## Requisitos previos

Tener instalado Docker y Docker Compose.

## Despliegue rápido

Para construir la imagen y levantar tanto la base de datos como la aplicación con un solo comando:

```bash
docker compose up --build
